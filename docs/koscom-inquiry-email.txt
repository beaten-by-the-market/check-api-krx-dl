제목: [CHECK API 문의] tick_date 특정 종목·일자 조합 조회 실패 건 (005930 / 20260507)


안녕하십니까.

CHECK API를 이용하여 체결 데이터를 수집하던 중, 특정 종목과 일자의 조합에서만
반복적으로 조회가 실패하는 현상이 있어 문의드립니다.

확인 부탁드립니다.


1. 요청 내용

   POST https://checkapi.koscom.co.kr/stock/m222/tick_date
   Content-Type: application/x-www-form-urlencoded

   cust_id    = (당사 고객번호)
   auth_key   = (당사 인증키)
   jcode      = 005930
   edate      = 20260507
   data_list  = F16604,F15019,F15001,F15020,F15022


2. 응답 내용

   HTTP 200 으로 응답되며, 본문은 아래와 같습니다.

   {"success": false, "message": "Error while performing Query."}

   data_list 파라미터를 제외하고 전체 필드로 요청하여도 동일한 응답을 받습니다.
   2026년 7월 23일부터 7월 27일까지 3일에 걸쳐 8회 이상 재시도하였으나
   모두 같은 결과였습니다.


3. 해당 조합에서만 발생함을 확인한 내용

   문의 전 아래 세 가지 가능성을 자체적으로 확인하였으며, 모두 해당되지
   않는 것으로 판단하였습니다.

   가. 해당 일자의 데이터가 전체적으로 부재한 경우

       2026년 5월 7일자로 NXT 거래종목 628개를 모두 조회한 결과
       628개 종목 전부 정상 응답되었습니다. (총 6,838,954건 수신)
       같은 일자의 대용량 종목도 정상 응답되었습니다.

           000660 (SK하이닉스)    406,038건
           028050                322,982건
           011790                243,184건

       해당 일자 종목 중 005930 만 조회되지 않았습니다.

   나. 응답 데이터가 과다하여 실패하는 경우

       동일 종목(005930)의 인접 거래일은 모두 정상 응답되었습니다.

           2026-05-04     350,673건
           2026-05-06     854,332건
           2026-05-07     조회 실패
           2026-05-08     593,301건
           2026-05-11     669,469건
           2026-05-12     859,377건
           2026-05-13     781,847건
           2026-05-14     539,542건
           2026-05-15     830,619건

       5월 12일에 859,377건, 5월 6일에 854,332건이 정상 반환되었으며
       이는 5월 7일의 예상 데이터 규모보다 큰 수준입니다.

   다. 보관 기간을 초과한 경우

       당사 실측 기준 tick_date 의 조회 가능 기간은 조회일로부터 약 101일입니다.
       최초 실패 시점인 2026년 7월 23일 기준으로 2026년 5월 7일은 77일 전으로
       보관 기간 이내에 해당합니다.


4. 문의 사항

   가. 2026년 5월 7일자 005930 체결 데이터가 서버에 정상적으로 적재되어
       있는지 확인 부탁드립니다.

   나. 적재 누락으로 확인될 경우 재적재가 가능한지, 가능하다면 예상 시점을
       알려주시면 감사하겠습니다.

   다. "Error while performing Query." 메시지가 보관 기간 초과와 서버 측
       조회 실패의 두 경우에 동일하게 반환되는 것으로 보입니다.
       두 상황을 구분할 수 있는 별도의 에러 코드가 제공된다면, 이용 기관에서
       재시도가 필요한 경우와 무의미한 경우를 판별할 수 있어 도움이 될 것으로
       생각됩니다. 검토 부탁드립니다.


5. 참고 사항

   - 등록 IP 환경에서 POST 방식(form-urlencoded)으로 호출하고 있으며,
     본 건 외 다른 요청은 모두 정상 처리되고 있습니다.
   - 초당 1건 이하로 순차 호출하고 있으며, 조회 제한 관련 메시지는
     수신되지 않았습니다.
   - 본 건을 제외한 2026년 4월 3일부터 5월 14일까지 구간의 조회 18,551건은
     모두 정상 응답되었습니다. (총 178,908,435건 수신)
